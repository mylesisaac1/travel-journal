*A beautiful digital journal to document your travel adventures with photos and memories. my travel journal is a digital travel journal designed for globetrotters, backpackers, and casual travelers to document their adventures in a personalized, organized, and visually appealing way. The app combines journaling, photo storage, mapping, and social sharing to create a seamless travel memory-keeping experience.*

## Features 🌟
- **Add Travel Entries** with location, date, description, and image URLs
- **Edit/Delete** existing entries with one click
- **Responsive Design** works perfectly on mobile/tablet/desktop
- **Image Gallery** with click-to-view functionality
- **Instant Search** entries by location or description
- **Local Storage** saves all data in your browser
- **Entry Management** (50 max limit) with counter

## How to Use 🛠️
1. **Add Entry**:
   - Click "Add Entry" in navigation
   - Fill location, date, description
   - Add image URL (e.g. `https://i.imgur.com/photo.jpg`)
   - Click "Save Entry"

2. **View Entries**:
   - All entries display on homepage
   - Click any image to view full-size in new tab

3. **Search**:
   - Type in search box
   - Results update instantly

4. **Edit/Delete**:
   - Click pencil icon to edit
   - Click trash icon to delete (with confirmation)
